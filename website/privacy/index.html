隐私说明

使用来电快检无需注册或登录。应用在手机上整理号码信息、保存标记和读取缓存。

号码发给谁

来电识别和手动查号都会先查手机上的缓存。没有有效缓存，或你点「重新查询」时，手机会把所查号码直接发给百度、360 搜索和搜狗搜索。开发者服务器不经手这些号码。搜索服务按各自的规则处理请求。手机上的系统 WebView 会保存搜索页面的 Cookie。

本机保存什么

有效查询结果及其来源会缓存 180 天，应用也会保存你添加的号码标记，以及最近一次系统来电检测的时间、号码和结果。你可以在应用中清除自己的标记。

系统备份与换机

当前 Android 版允许系统备份和换机迁移。开启这些功能时，系统可能把应用数据复制到备份服务或新设备。你可以在手机的系统备份设置中查看或调整。卸载应用会删除本机应用数据，已有备份由系统管理。

系统权限用在哪里

系统来电识别角色用于接收待识别号码。通知与全屏提醒用于展示检测卡片，临时浮层用于后台查询。应用不读取完整通话记录或其他应用的通知。

查看开源实现

此软件来自AI系统独立开发者：常见。你可以在 Android 客户端源码中查看联网查询、缓存与权限的实现。原创代码采用 MIT 许可证，第三方组件和数据保留各自的许可证。

更新、下载与反馈

打开主页面或手动检查更新时，应用会请求应用工厂的公开版本信息，仅提交平台和应用标识。当前版本没有账户、广告 SDK 或统计 SDK。点击下载或反馈时，会打开相应的外部网站。

如果你对数据处理有疑问，可以在 GitHub 反馈区留言。反馈内容公开可见，请先遮挡电话号码和通话截图里的个人信息。
