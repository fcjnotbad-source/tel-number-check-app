隐私说明

来电快检使用手机上的系统 WebView 查询号码。你可以在这里了解一次查询涉及哪些数据。

号码发给谁

启用来电识别后，遇到没有有效本机缓存的陌生号码，设备会把号码提交给百度、360 搜索和搜狗搜索。手动联网查询也会提交所查号码。搜索服务按各自的规则处理请求，WebView 在设备上保存搜索页面的 Cookie。开发者服务器不经手号码查询。应用只提取号码查询服务卡提供的信息。

本机保存什么

有效查询结果及其来源会缓存 180 天，应用也会保存你添加的号码标记，以及最近一次系统来电检测的时间、号码和结果。你可以在应用中清除自己的标记，卸载应用会删除本机应用数据。

系统权限用在哪里

系统来电识别角色用于接收待识别号码。通知与全屏提醒用于展示检测卡片，临时浮层用于后台查询。应用不读取完整通话记录或其他应用的通知。

更新、下载与反馈

打开主页面或手动检查更新时，应用会请求应用工厂的公开版本信息，仅提交平台和应用标识。当前版本没有账户、广告 SDK 或统计 SDK。点击下载或反馈时，会打开相应的外部网站。

如果你对数据处理有疑问，可以在 GitHub 反馈区留言。反馈内容公开可见，请先遮挡电话号码和通话截图里的个人信息。
